# Marketplace - платформа электронной коммерции

Web-приложение на Spring MVC для торговой площадки с поддержкой нескольких ролей пользователей, корзины покупок, системы заказов и отзывов.

## Основные возможности

**Система ролей:**
- Покупатель (USER) - просмотр и покупка товаров
- Продавец (SELLER) - размещение и продажа товаров
- Администратор (ADMIN) - управление платформой

**Каталог товаров:**
- Поиск по названию (без учета регистра)
- Сортировка по дате, цене и рейтингу
- Автоматическое скрытие товаров с нулевым остатком
- Детальная информация о товаре в модальном окне

**Система отзывов:**
- Оценка товаров от 1 до 5 баллов
- Отзывы доступны только после покупки товара
- Отображение средней оценки на карточках товаров

**Корзина и заказы:**
- Добавление товаров в корзину
- Изменение количества перед оформлением
- Выбор адреса доставки и способа оплаты
- Полная история заказов

**Административная панель:**
- Просмотр всех пользователей и их заказов
- Управление товарами и пользователями
- Статистика по платформе

## Технологический стек

- **Backend:** Spring MVC 6.0, Hibernate 6.4 (JPA)
- **Frontend:** JSP, JSTL, JavaScript, CSS
- **БД:** MySQL 8.0 с HikariCP connection pool
- **Безопасность:** BCrypt для хэширования паролей
- **Сборка:** Maven
- **Сервер:** Apache Tomcat 10.1

## Установка и запуск

### Требования

- JDK 17 или выше
- Apache Tomcat 10.1+
- MySQL 8.0+
- Maven 3.6+

### Настройка проекта

1. Клонируйте репозиторий:
```bash
git clone https://github.com/YOUR_USERNAME/marketplace.git
cd marketplace
```

2. Создайте базу данных MySQL:
```sql
CREATE DATABASE marketplace_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

**Все таблицы создадутся автоматически** при первом запуске приложения благодаря Hibernate (настройка `hibernate.hbm2ddl.auto=update` в конфигурации). SQL скрипты не требуются.

3. Настройте подключение к БД:
```bash
cp db.properties.example src/main/resources/db.properties
```

Откройте `src/main/resources/db.properties` и укажите свои данные:
```properties
db.driver=com.mysql.cj.jdbc.Driver
db.url=jdbc:mysql://localhost:3306/marketplace_db?useSSL=false&serverTimezone=UTC
db.username=your_username
db.password=your_password
```

5. Соберите проект:
```bash
mvn clean install
```

6. Разверните WAR файл на Tomcat:
- Скопируйте файл из `target/marketplace.war` в папку `webapps` вашего Tomcat
- Или настройте деплой через IDE (IntelliJ IDEA)

7. Запустите приложение:
```
http://localhost:8080/marketplace_war_exploded/
```

## Особенности реализации

**Безопасность:**
- Пароли пользователей хэшируются через BCrypt
- Проверка прав доступа на каждом эндпоинте
- Конфиденциальные данные вынесены в отдельный файл

**Архивирование товаров:**
При удалении продавца его товары не удаляются из системы, а становятся архивными (связь с пользователем обнуляется). Это сохраняет целостность истории заказов.

**Защита целостности данных:**
Товар нельзя удалить, если он присутствует в чьих-либо заказах. Система выводит соответствующее предупреждение.

**Ограничения по ролям:**
- Продавец не может купить свой собственный товар
- Продавец не видит свои товары в общем каталоге
- Администратор не имеет доступа к функциям покупки/продажи
